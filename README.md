# 🫁 PneumoScan AI — Pneumonia Detection System

An end-to-end AI system for detecting pneumonia from chest X-ray images using deep learning and a modern web interface.

---

## 🚀 Features

* Upload chest X-ray images
* Real-time prediction (Pneumonia / Normal)
* Clean, modern UI built with Streamlit
* Model hosted on Hugging Face (dynamic loading)

---

## 🧠 Tech Stack

* Python
* TensorFlow / Keras
* Streamlit
* NumPy, Pillow
* Hugging Face (model hosting)

---

## 🏗️ System Architecture

User → Upload Image → Preprocessing → Deep Learning Model → Prediction → UI Display

---

## 📦 Model Hosting

Due to size limitations, the trained model is hosted on Hugging Face and automatically downloaded at runtime.

🔗 Model Link:
https://huggingface.co/Sahil200217/pneumonia-detection-model

---

## ▶️ How to Run Locally

```bash
pip install -r requirements.txt
streamlit run app.py
```
